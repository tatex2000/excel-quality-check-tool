\# Excelの一覧データ／組織図／マスタの入力ミスを一括チェックするVBAツールを作った



Excelで管理している \*\*一覧データ／組織図／マスタ\*\* の入力ミス・重複・空白・マスタ不一致などを一括チェックするために作成したVBAツールです。



入力ミスの確認だけでなく、データ整備や品質確認にも利用できることを想定しています。



\---



\## 【このツールの強み】



\### ① 一覧データと管理系Excelの両方に対応



```text

社員一覧 / 顧客一覧 / 異動一覧

組織図 / 部署マスタ / 会社マスタ / コード表

```



一覧型Excelだけでなく、管理系Excelにも利用できます。



\---



\### ② 実務でよくあるExcel形式に対応



```text

ヘッダあり / ヘッダなし / タイトル行付き

```



ヘッダ行が途中にあるファイルや説明行付きファイルでも取り込めます。



\---



\### ③ 入力ミス以外も確認可能



```text

空白 / 重複 / 表記ゆれ候補

マスタ未登録 / 入力漏れ

データ不整合

```



を確認できます。



\---



\## 【このツールの対象範囲】



\### 一覧データ系



```text

社員一覧 / 顧客一覧 / 異動データ

CSV / 申請一覧 / 作業一覧

```



\### 組織図・マスタ系



```text

組織図 / 部署マスタ / 会社マスタ

評価マスタ / コード表 / 設定表

```

\# 使用例①【基本編】氏名の空白・重複をチェックする



今回は社員一覧を使って、氏名の空白・重複を確認します。



対象データはこちらです。



!\[元データ](images/sample\_input.png)



```text

氏名        部署      会社

山田太郎    人事      ABC

山田 太郎   人事      ABC

佐藤花子    営業      XYZ

```



この例では、



```text

山田太郎

山田 太郎

```



のようなスペース違いを確認します。



同一人物でも別データとして扱われる原因になるため、実務では見落としやすいポイントです。



\---



設定するルールはこちらです。



!\[ルール入力](images/rule\_basic.png)



今回使ったルールは次の2つだけです。



```text

氏名

→ 【空白】チェック（総合）



氏名

→ 【重複】スペース違いを無視して重複チェック

```



まずは最もシンプルな使い方です。



\---



実行すると、判定一覧に検出結果が表示されます。



!\[判定一覧](images/result\_list.png)



\- 山田 太郎  

→ 空白として検出



\- 山田太郎 / 山田 太郎  

→ 重複候補として検出



\---



結果は最終判定へ集約されます。



!\[最終判定](images/final\_result.png)



判定一覧が詳細確認用なら、最終判定は件数・対象行の整理用です。



修正対象の確認や報告用として使えます。



\---



\# 使用例②【応用編】会社マスタと照合する



次は会社名がマスタに登録されているか確認する例です。



```text

氏名        部署      会社

山田太郎    人事      ABC

佐藤花子    営業      XYZ

田中次郎    開発      未登録会社

```



会社マスタ



```text

ABC

XYZ

```



設定例



```text

対象項目：会社

ルール：【マスタ】完全一致しない

条件値：会社マスタ

```



結果



```text

未登録会社

→ NG

```



入力ミス、マスタ未登録、登録漏れ候補を確認できます。



\---



\# 使用例③【応用編】氏名＋部署で重複を確認する



```text

氏名        部署

山田太郎    人事

山田 太郎   人事

山田太郎    総務

```



設定



```text

対象項目：氏名

ルール：重複（スペース違い無視）

結合キー：部署

```



結果



```text

山田太郎 + 人事

山田 太郎 + 人事

→ 重複候補



山田太郎 + 総務

→ 別データ扱い

```
